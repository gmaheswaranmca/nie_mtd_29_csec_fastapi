const [num, setNum] = useState(0);

Here useState is the hook to define the "num" state.
num has init value 0.

useState function returns array of two elements.
first element is state element - read only 
second element is function element - it is used to set the state 

state data can be number, str, object or array.

src/Square.jsx
```
import { useState } from "react";

export default function Square() {
    const [num, setNum] = useState(0);
    const [sqr, setSqr] = useState(0);
    return (
        <>
            <p>Number : <input type="text" 
                value={num} onChange={ (e) => {setNum(parseInt(e.target.value));} }/></p>
            <p><button onClick={ () => {setSqr(num * num);} }>Calculate</button></p>
            <p>Square of {num} is {sqr}</p>
        </>
    )
}
```
